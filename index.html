Kenapa muncul "404: NOT_FOUND (sin1::...)" di Vercel?

Error 404 NOT_FOUND di Vercel terjadi jika: (1) Nama file utama bukan index.html (huruf kecil semua), atau (2) File berada di dalam sub-folder lagi, atau (3) Tidak ada file konfigurasi vercel.json.
